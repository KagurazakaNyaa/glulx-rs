# 兼容性

[English](compatibility.md) | [中文](compatibility.ZH.md)

实现目标为 Glulx 3.1.3 和 Glk 0.7.6。覆盖范围及可复现证据见[规范清单](glulx-spec-checklist.ZH.md)和[验收记录](glulx-validation.ZH.md)。这不代表已证明完全符合规范。

## 已实现

- 校验原始 Glulx 和带索引的 Blorb 可执行文件、图像、声音/数据资源、iFiction 元数据、封面及 RDes 图像/声音描述。
- 标准整数、寻址、调用、搜索、字符串、单/双精度和堆指令。
- 与 Glulxe 互操作的 IFZS 持久存档、restart/protect 及多级 undo 状态。
- Inform 加速函数 1–13，包含类/属性访问及旧版/当前对象布局；按规范移除不支持的注册。
- 配对窗口树、文本缓冲区/网格、图形窗口、文件/内存/资源流和 Unicode 操作。
- 多个输入请求、事件队列、定时器、鼠标、超链接、行终止键和回显控制。
- 文本样式、行内/边缘图像、日期时间 API，以及支持重复、暂停、渐变和通知的声道。
- 桌面文件提示、打开/重启/停止、历史输出、设置、翻译和自动会话恢复。

## 资源选择与终端游玩

原始 `.ulx` 可通过 `Story::open_with_resources`、`--resources PATH` 或 File → Choose resources 挂载无执行文件的 Blorb 或散装资源目录。有 `IFhd` 时必须匹配 Glulx 故事前 128 字节，无该块也可加载。执行文件冲突、损坏包和错误身份会在替换状态前失败。GUI 通过重启故事应用选择并清理图片/封面缓存和活动声音；选择失败保留当前游戏。

原始故事的同名发现顺序为 `.blorb`、`.blb`、`.gblorb`、`.glb`。文件主名精确匹配，扩展名不区分 ASCII 大小写，同优先级多个候选报歧义。`--resources` 优先于自动发现，`--no-auto-resources` 禁用发现。选中资源完整替换资源映射。桌面会话内嵌资源内容并保留来源，原包或目录删除后仍可恢复；可移植 IFZS 仍只保存规范中的 VM 状态。

散装目录需显式选择，不递归扫描。编号 `PIC` 支持 PNG/JPEG，`SND` 支持 AIFF/OGG/MP3/MOD/XM/S3M/IT/SONG，`DATA` 支持 TEXT/BINA/FORM。命名及编号前缀不区分 ASCII 大小写，重复编号或无效的已编号资源报错。元数据名包括 IDENT、FRONTIS、RESDESC 和 METADATA。无关文件忽略，STORY 资源按冲突执行文件拒绝；后缀和示例见资源映射验收工具。

`--headless` 在真实 TTY 中显示文本缓冲区、网格和状态窗口，支持预填编辑、定时取消和即时无回显字符输入。Ctrl+N 切换待输入窗口，Ctrl+C 退出，空编辑器下 Ctrl+D 退出。正常或错误退出均恢复终端模式和原屏幕。stdin/stdout 任一为管道时使用稳定文本/文件协议，并拒绝创建不支持的网格和图形窗口。终端不声明图像、鼠标、超链接输入或声音；非单列字符显示为 `?` 并通过 CharOutput 报告 CannotPrint，Unicode 输入和文件数据仍保留。

## 限制

虚拟机内存上限可配置，默认为 1024 MiB。Undo 最多保留 16 份快照，可配置的数据预算默认为 256 MiB，计入内存、初始映像、栈及堆记录，不含容器和分配器开销。日志窗口的 transcript 最多保留 4 MiB 或 100,000 行，显示本身使用虚拟行；这只限制播放器历史，不截断 VM 的原始输出。各项资源及进程硬上限见[内存额度说明](../README.ZH.md#性能与内存额度)。旧快照会被淘汰，超大保存请求会失败。setmemsize/malloc 处理配置上限及内存预留失败；这不保证能从所有进程内存分配失败中恢复。可移植 IFZS 按规范排除 Glk、RNG、I/O 系统和字符串表状态；独立的带版本桌面会话包含宿主状态和打包的故事数据。桌面会话是播放器本地快照，不是交换格式。

文本缓冲区支持全部五种图像对齐方式、边缘图像流中断、图片超链接，以及 Glk 0.7.6 动态宽度/宽高比/最大宽度规则。图形窗口图像保留绘制时的尺寸；缩放仅采样可见画布像素，包括无符号目标尺寸极大的情况。PNG/JPEG 资源完全解码后才返回 Glk 图像成功结果。单张图片 RGBA 输出上限可配置，默认为 256 MiB，解码器分配预算为该上限的两倍；不可用图像返回失败。故事信息中可查看 RDes 文字替代描述。支持文本缓冲区样式提示 0–9，已实现段落缩进/悬挂缩进和全部四种对齐模式。网格单元保留样式和超链接；为保持单元尺寸一致，忽略网格布局提示 0–3/6，但应用字重/斜体/颜色提示。度量反映实际呈现；有相应字体时选择真实的比例/等宽 light 字重，否则如实回退为常规。通过字体元数据校验字重，不能只信文件名；会话恢复后重新安装宿主字体可用性。自动加载系统轮廓字体，Options 允许添加额外的 TTF/OTF/TTC 回退字体。CharOutput 准确报告缺失字形。文本缓冲区窗口尺寸使用普通样式的实际字体度量，网格保持统一的 8×16 单元。

声音解码使用 rodio/Symphonia，以及纯 Rust 的 xmrs/xmrsplayer，支持全部四种标准 Blorb tracker 格式：MOD、XM、S3M 和 IT。Tracker 与采样音频均在播放时解码。有限重复在解码器自然 EOF 处结束，保留每个 PCM 样本和立体声帧。利用容器帧数去除编码器填充，重采样在数据包和重复边界间保持连续。不承诺逐比特复现每一种历史 tracker 变体。`play_multi` 提交单个混合输出音源，使各声道对齐到同一个立体声采样帧；尚未测量实体声卡输出。AIFF、生成的 MOD 和 SONG 资源有 GUI 覆盖，但并非每种 codec/编码组合都有样本。可选旧 SONG 格式解析共享 `SND<number>` AIFF 样本、SSND offset 和 MARK/INST sustain loop（无循环、正向、往返）。样本转换为 16 位单声道（多声道平均，高位深舍弃低位），音高遵循 MOD period/finetune。SONG 使用可配置的音频资源上限（默认 256 MiB），不同引用样本的解码 PCM 共用可配置的额度（默认 128 MiB）；错误/缺失引用返回失败，重复、暂停、通知和恢复复用公共音频路径。

文件流保留编码字节位置和 Unicode 覆写语义，同一文件的并发流共享内容但位置独立。文件提示拒绝不存在的读取路径，并在修改已有文件前确认。取消输入会回显保留的组成文本，行终止键绑定到各个请求，select_poll 将玩家输入留给 select。GUI 支持标准特殊按键和直接在网格窗口中编辑。

无界面适配器提供终端文本和文件提示，不宣称支持 GUI 专属功能。没有音频输出设备时，桌面禁用声音能力。Gestalt 查询考虑参数及宿主可用性。未知 Glk selector 返回零并被记录；不支持的虚拟机指令产生类型化错误。游戏成功启动不一定意味着可以完整游玩。

日期转换在有符号 32 位年份范围内使用公历运算；本地时间保留历史偏移和未来循环时区规则。IFZS 恢复按 Quetzal 规范接受可重复的注释/扩展块，并忽略后续重复的单实例块。

验证包括官方 Glulxercise、Unicode 和资源流测试套件、Adventure 存档互操作，以及 Linux 桌面冒烟测试。Windows/macOS 运行行为及完整游戏路线仍不在本次验证范围内。
