# 兼容性

[English](compatibility.md) | [中文](compatibility.ZH.md)

实现目标为 Glulx 3.1.3 和 Glk 0.7.6。覆盖范围及可复现证据见[规范清单](glulx-spec-checklist.ZH.md)和[验收记录](glulx-validation.ZH.md)。这不代表已证明完全符合规范。

## 已实现

- 校验原始 Glulx 和带索引的 Blorb 可执行文件、图像、声音/数据资源、iFiction 元数据、封面及 RDes 图像/声音描述。
- 标准整数、寻址、调用、搜索、字符串、单/双精度和堆指令。
- 与 Glulxe 互操作的 IFZS 持久存档、restart/protect 及多级 undo 状态。
- Inform 加速函数 1–13，包含类/属性访问及旧版/当前对象布局；按规范移除不支持的注册。
- 配对窗口树、文本缓冲区/网格、图形窗口、文件/内存/资源流和 Unicode 操作。
- 多个输入请求、事件队列、定时器、鼠标、超链接、行终止键和回显控制。
- 文本样式、行内/边缘图像、日期时间 API，以及支持重复、暂停、渐变和通知的声道。
- 桌面文件提示、打开/重启/停止、历史输出、设置、翻译和自动会话恢复。

## 尚未实现

原始 `.ulx` 文件不能通过 GUI、CLI 或公共 API 挂载独立的 Blorb 资源包，播放器也不会发现同名资源包。目前只读取故事自身 Blorb 容器中的资源。独立资源包选择和会话恢复已登记在规范清单中。Blorb IFhd 身份检查和执行文件/资源参数冲突也需要覆盖。散装 PIC/SND/DATA 资源目录加载是尚未实现的可选播放器功能。容器校验目前容忍非零 padding 和未索引 GLUL 的回退读取，不会拒绝所有畸形资源包。

已弃用的可选 Blorb `SONG` 格式尚未实现；该格式引用存储在独立资源中的 AIFF 样本。

当前无界面循环是面向行输入的自动化适配器。它不渲染文本网格/状态窗口，也不提供终端预填文本编辑、实时输入取消，或无需 Enter 的即时字符输入。真正的终端宿主尚待实现，其能力报告必须与支持的窗口和输入一致。

轻字重请求目前按常规字重渲染；实际轻字重字体的选择也尚待实现。

## 限制

虚拟机内存上限为 256 MiB。Undo 最多保留 16 份快照，估算预算为 64 MiB，计入内存、栈和故事映像，不含堆索引及分配器开销。旧快照会被淘汰，超大保存请求会失败。setmemsize/malloc 处理配置上限及内存预留失败；这不保证能从所有进程内存分配失败中恢复。可移植 IFZS 按规范排除 Glk、RNG、I/O 系统和字符串表状态；独立的带版本桌面会话包含宿主状态和打包的故事数据。桌面会话是播放器本地快照，不是交换格式。

文本缓冲区支持全部五种图像对齐方式、边缘图像流中断、图片超链接，以及 Glk 0.7.6 动态宽度/宽高比/最大宽度规则。图形窗口图像保留绘制时的尺寸；缩放仅采样可见画布像素，包括无符号目标尺寸极大的情况。PNG/JPEG 资源完全解码后才返回 Glk 图像成功结果。解码源图像限制为 1600 万像素，解码器分配预算为 128 MiB；不可用图像返回失败。故事信息中可查看 RDes 文字替代描述。支持文本缓冲区样式提示 0–9，已实现段落缩进/悬挂缩进和全部四种对齐模式。网格单元保留样式和超链接；为保持单元尺寸一致，忽略网格布局提示 0–3/6，但应用字重/斜体/颜色提示。度量反映实际呈现；轻字重请求目前回退为常规字重。自动加载系统轮廓字体，Options 允许添加额外的 TTF/OTF/TTC 回退字体。CharOutput 准确报告缺失字形。文本缓冲区窗口尺寸使用普通样式的实际字体度量，网格保持统一的 8×16 单元。

声音解码使用 rodio/Symphonia，以及纯 Rust 的 xmrs/xmrsplayer，支持全部四种标准 Blorb tracker 格式：MOD、XM、S3M 和 IT。Tracker 与采样音频均在播放时解码。有限重复在解码器自然 EOF 处结束，保留每个 PCM 样本和立体声帧。利用容器帧数去除编码器填充，重采样在数据包和重复边界间保持连续。不承诺逐比特复现每一种历史 tracker 变体。`play_multi` 提交单个混合输出音源，使各声道对齐到同一个立体声采样帧；尚未测量实体声卡输出。AIFF 和生成的 MOD 资源有 GUI 覆盖，但并非每种 codec/编码组合都有样本。

文件流保留编码字节位置和 Unicode 覆写语义，同一文件的并发流共享内容但位置独立。文件提示拒绝不存在的读取路径，并在修改已有文件前确认。取消输入会回显保留的组成文本，行终止键绑定到各个请求，select_poll 将玩家输入留给 select。GUI 支持标准特殊按键和直接在网格窗口中编辑。

无界面适配器提供终端文本和文件提示，不宣称支持 GUI 专属功能。没有音频输出设备时，桌面禁用声音能力。Gestalt 查询考虑参数及宿主可用性。未知 Glk selector 返回零并被记录；不支持的虚拟机指令产生类型化错误。游戏成功启动不一定意味着可以完整游玩。

日期转换在有符号 32 位年份范围内使用公历运算；本地时间保留历史偏移和未来循环时区规则。IFZS 恢复按 Quetzal 规范接受可重复的注释/扩展块，并忽略后续重复的单实例块。

验证包括官方 Glulxercise、Unicode 和资源流测试套件、Adventure 存档互操作，以及 Linux 桌面冒烟测试。Windows/macOS 运行行为及完整游戏路线仍不在本次验证范围内。
